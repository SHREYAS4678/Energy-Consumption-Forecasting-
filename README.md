# ⚡ Energy Consumption Forecasting

## 📌 Problem
Predict electricity consumption using machine learning.

## 📊 Dataset
Kaggle - Hourly Energy Consumption Dataset

## ⚙️ Features
- Hour, Day, Month
- Lag Features
- Rolling Mean
- Weekend Indicator

## 🤖 Models Used
- Linear Regression
- Random Forest
- XGBoost

## 📈 Performance
- R² Score: 0.85+
- RMSE: Low

## 🚀 Features
- Real-time prediction
- Peak load detection
- Anomaly detection
- 24-hour forecasting

## 🖥️ Dashboard
Built using Streamlit

## 📦 How to Run
```bash
streamlit run app.py
